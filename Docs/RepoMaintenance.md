**Track vs Not Track Policy**
- Track a file when it is required to build, run, test, or document project behavior across all developer machines.
- Do not track a file when it is generated at runtime, machine-specific, credential-bearing, or reproducible from source.

**Do Not Track Triggers**
- Secrets: credentials, tokens, private keys, service-account material.
- Machine-local settings: local override configs, browser profiles, local paths.
- Runtime artifacts: logs, screenshots, exports, queue snapshots, lock files, temporary database files.
- Tool caches: bytecode, pytest/mypy/ruff caches, coverage outputs.
- Rebuildable outputs: files created by scripts or test runs that are not canonical inputs.

**Track Triggers**
- Source code: Python modules, command scripts, reusable tooling.
- Tests and fixtures that define expected behavior.
- Stable documentation and runbooks.
- Canonical templates/config defaults needed by every clone.

**Decision Gate (all must pass to keep tracked)**
- File has team-shared value outside one machine.
- File is not secret-bearing.
- File is not auto-generated by normal execution.
- File is needed for deterministic onboarding, runtime, or tests.

**When A Tracked File Should Become Untracked**
- It frequently changes as runtime output and creates commit noise.
- It contains environment-specific data that should not be shared.
- It can be regenerated from tracked inputs.
- It has no contractual role in requirements, tests, or release behavior.

**CSV Convention (.local.csv)**
- Keep shared CSV templates tracked.
- Use a local working copy with `.local.csv` suffix for machine-specific or run-specific edits.
- `.local.csv` files are ignored by default in [.gitignore](.gitignore).
- Prefer this pattern for operational CSV flows where schema is shared but row content is local.

**INI Convention (.local.ini)**
- Keep shared `.ini` defaults tracked when they define team-wide behavior.
- Use `.local.ini` for machine-specific overrides.
- `.local.ini` files are ignored by default in [.gitignore](.gitignore).

**JSON Convention (.local.json)**
- Keep shared `.json` defaults and schemas tracked.
- Use `.local.json` for machine-specific or credential-adjacent local overrides.
- `.local.json` files are ignored by default in [.gitignore](.gitignore).

**Safe Conversion Steps**
- Add a targeted pattern to [.gitignore](.gitignore).
- Remove from index only (keep local file): git rm --cached <path>
- Commit with a maintenance message describing why the file became untracked.
- Re-run baseline tests to verify no behavior regression.
